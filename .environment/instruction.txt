Installation
━━━━━━━━━━━━
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
eval "$(/opt/homebrew/bin/brew shellenv)"
```

Brewfile management
━━━━━━━━━━━━━━━━━━━
⁃ Update  → `/opt/homebrew/bin/brew bundle install`
⁃ Cleanup → `/opt/homebrew/bin/brew bundle cleanup --force`

Metadata
━━━━━━━━
⁃ MPEG Write Options        → only ID3v2
⁃ ID3v2 Version             → ID3v2.4 (UTF-16)
⁃ ID3v2 Compatibility Mode: → undo iTunes

Artwork
━━━━━━━
⁃ Format              → JPEG
⁃ Compression         → pull to the maximum right
⁃ Square Ratio (Crop) → Tick
⁃ Max Size            → 700 x 700 px

Editing
━━━━━━━
⁃ Undefined Metadata in Patterns → Replace with placeholder
⁃ File and Folder Names          → Tick all to Compatible
