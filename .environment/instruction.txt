『curl -L https://nixos.org/nix/install | sh』

𖣠 Cleanup
『nix-collect-garbage』

𖣠 Unlink packages
1)『nix profile remove <title the packages are under>』
2)『nix profile remove --all』

𖣠 Binary deletion
1) 『nix store gc』
2) 『nix-collect-garbage -d』

𖣠 Flake management
⁃ First run 𐃘 『sudo nix run nix-darwin --extra-experimental-features "nix-command flakes" -- switch --flake .#<name of the build in the flake>』
⁃ Run       𐃘 『nix run nix-darwin -- switch --flake .#<name of the build in the flake>』
⁃ Update    𐃘 『nix flake update』
⁃ Roll back 𐃘 『nix run nix-darwin -- switch --rollback』
